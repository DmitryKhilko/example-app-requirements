# Выписка заказов в виде бумажного чека

## Описание

Выгрузка истории заказов в печатной форме. Статус в метаданных не обновлён, но файл лежит в архиве.

## Основной сценарий

1. Клиент выбирает заказы и нажимает «Печать».

## Критерии приёмки

- Фича выведена из эксплуатации.
