# Дисконтные карты старого образца

## Описание

Привязка дисконтных карт, выпущенных до 2024 года. Программа лояльности закрыта.

## Основной сценарий

1. Пользователь вводит номер карты.
2. Система проверяет карту в архивной базе.

## Критерии приёмки

- Фича выведена из эксплуатации.
