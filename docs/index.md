# О программном продукте

Пример организации базы знаний программного продукта, которая содержит:

- Информацию, связанную с управлением проекта создания/сопровождения продукта. 
- Информацию, связанную с управлением качества продукта.  
- Информацию, связанную с управлением требованиями к продукту. 
 
Статьи базы знаний создаются с использованием подхода Docs as Code: 

- **Создание статей базы знаний**: Статьи создаются в VS Code как Markdown-файлы. 
- **Сохранение статей базы знаний**: При сохранении Markdown-файлов производится автоматическая проверка качества статьи 
с помощью Python-скрипт. Созданные Markdown-файлы хранятся как на локальном ПК пользователя, так и в централизованном 
Git-репозитории. 
- **Генерация статического сайта**: При каждой заливке изменений в ветку main в централизованном Git-репозитории 
автоматически генерируется статический сайт, отображающий в удобном формате Markdown-файлы, созданные пользователем или 
сгенерированные автоматически Python-скриптами. Сгенерированный сайт могут просматривать: разработчики, представители 
Заказчика.
