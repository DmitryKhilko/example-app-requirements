# Глоссарий {#glossary}

## Обзор статьи {#article-overview}

В процессе создания программного продукта глоссарий служит **единым источником правды**, устраняющим «трудности 
перевода» между бизнесом, аналитиками, разработчиками и QA. В статье приведены базовые термины, используемые в кодовой 
базе и документации по программному продукту.

Фиксация терминов помогает проекту:

- **Синхронизировать команду:** Устанавливает единый язык для Заказчиков и разработчиков.
- **Сохранять чистоту кода:** Гарантирует, что сущности в архитектуре и базах данных называются строго в соответствии с 
бизнес-логикой.
- **Исключать логические ошибки:** Помогает разграничить похожие понятия на стыке разных систем и отделов.
- **Ускорять процессы:** Сокращает время на онбординг новичков и согласование новых проектных требований.
