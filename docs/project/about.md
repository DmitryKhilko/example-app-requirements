# О программном продукте

Пример организации требований для программного продукта с использованием подхода Docs as Code: спецификации 
функциональностей продукта хранятся в репозитории как Markdown-файлы, а обзор спецификаций, перечни действующих и 
архивных требований, страница релизов и меню сайта собираются автоматически.

## Структура сайта {#site-structure}

Сайт состоит из трёх разделов — они расположены в горизонтальном меню сверху. Страницы выбранного раздела показаны
в левом меню.

### Проект {#section-project}

Описание продукта и план его развития. Эта страница — первая в разделе.

<div class="grid cards" markdown>

- :lucide-book-open: [**Глоссарий**](glossary.md#article-overview)

    Перечень терминов, описывающих предметную область программного продукта. Он необходим для того, чтобы вся команда 
    одинаково понимала используемые понятия.

- :lucide-map: [**Roadmap**](roadmap.md#article-overview)

    План развития продукта: этапы, цели и принципы приоритизации. Показывает, зачем и в каком порядке появляются
    новые функциональности.

</div>

### Реестр требований {#section-registry}

База спецификаций продукта, организованная по модулям и субмодулям. Раздел открывается страницей «Обзор».

<div class="grid cards" markdown>

- :lucide-files: [**Обзор**](../registry/overview.md#overview)

    Все спецификации продукта с их статусами: общие итоги, плитки-фильтры по статусам, отбор по названию и два списка —
    действующие и архивные требования. Страница собирается автоматически.

- :lucide-file-check: [**Действующие**](../registry/active/index.md)

    Требования, которые находятся в работе или уже реализованы. Модули и субмодули для удобной навигации по
    архитектуре системы.

- :lucide-archive: [**Архив**](../registry/archive/index.md)

    Историческая база отклонённых и устаревших требований. Повторяет структуру модулей и субмодулей, что позволяет
    легко найти контекст старых решений.

</div>

### Релизы {#section-releases}

<div class="grid cards" markdown>

- :lucide-rocket: [**Релизы программного продукта**](../releases.md#releases)

    Перечень релизов продукта от новых к старым. В каждом релизе — список вошедших в него спецификаций с кратким
    описанием; список релиза можно скачать в текстовый файл.

</div>
